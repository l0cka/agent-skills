# Executive Dysfunction plugin

Evidence-informed executive-function assistance for Codex and Claude Code.

## Skill

- `executive-dysfunction`: identifies one work bottleneck, externalises the current state, and helps execute one low-friction next action.

## Boundaries

The skill does not diagnose ADHD, provide medication advice, or replace professional care. Persistent reminders, monitoring, and third-party contact require explicit consent.

## Evidence

The bundled evidence note distinguishes guideline-backed practices, trial-supported components, and indirect or preference-based techniques.
