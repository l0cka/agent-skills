# Method provenance

## Primary source

*Algorithmic Trading Methods: Applications Using Advanced Statistics,
Optimization, and Machine Learning Techniques*, second edition, Academic Press /
Elsevier, 2021.

## How the plugin uses the source

The focused skills are original, task-oriented workflows informed by these
topic ranges:

| Skill | Main source chapters |
| --- | --- |
| `design-algorithmic-execution` | 1, 2, and 13 |
| `analyze-transaction-costs` | 3, 18, 20, and 21 |
| `model-market-impact` | 4, 10, and 16 |
| `validate-trading-models` | 5 through 10, 16, and 19 |
| `forecast-market-volume` | 2 and 12 |
| `model-execution-risk` | 11, 14, and 15 |
| `optimize-trade-schedules` | 13 through 15 and 19 |
| `integrate-cost-aware-portfolios` | 17 and 18 |

The plugin presents independently written operational methods with modern
validation and live-risk controls. It does not bundle source text, figures,
tables, datasets, examples, or proprietary software. Short generic equations
use standard industry notation.

## Interpretation boundaries

- Treat the source as a conceptual foundation, not a current venue, regulatory,
  or market-structure specification.
- Validate every empirical relationship on the user's own instruments, period,
  venues, and order flow.
- Treat named models and broker estimates as hypotheses to challenge, not
  objective ground truth.
- Cite this source when its framework materially shapes an analysis. Cite
  additional primary sources for claims that go beyond it.
- Do not imply endorsement by the author or publisher.
